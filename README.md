# ALFA Kits Corporativos

Projeto de site para a aula do Senai.

## Descrição

Site institucional simples para a empresa ALFA Kits Corporativos, apresentando:

- Página inicial com resumo da empresa
- Seção Sobre com produtos e informações
- Formulário de contato funcional
- Navegação interativa em uma página principal

## Tecnologias usadas

- HTML
- CSS
- JavaScript

## Estrutura do projeto

- `index.html` - página principal com navegação por hash e seções de conteúdo
- `sobre.html` - página sobre a empresa e galeria de produtos
- `contato.html` - página de contato com formulário
- `styles.css` - estilos do site
- `script.js` - lógica de navegação e envio de formulário
- `imagens/` - imagens de produtos e portfólio
- `favicon/` - ícone do site

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Navegue entre as seções `Inicial`, `Sobre` e `Contato`.
3. No formulário de contato, preencha os campos e clique em enviar.

## Observações

- O site foi desenvolvido como projeto de aula do Senai.
- A navegação em `index.html` utiliza hash para exibir seções sem recarregar a página.
- O formulário exibe uma mensagem de sucesso ao enviar.
